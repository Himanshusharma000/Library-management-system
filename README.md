# 📚 LIBTrack — Library Management System

A Python + SQLite library management system for handling books, members, issuing/returning books, and issue history.

## ✨ Features
- Add and view books
- Register and view members
- Issue and return books with status tracking
- Persistent SQLite database
- Issue-history reporting
- Input validation for common book-flow cases

## 🛠️ Tech Stack
`Python` `SQLite` `SQL` `Database Management`

## 🚀 Run locally
```bash
python "project python.py"
```

The application creates `library.db` automatically on first run.
